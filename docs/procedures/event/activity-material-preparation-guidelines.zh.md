## 什么时候需要单独跟进物资

如果活动涉及较多物资、嘉宾、媒体设备、运动项目，或者报名人数较多，建议参考[活动与宣传流程](./README.zh.md)，在活动主 Issue 下单独建立：

```text
[task] 活动名称 - 准备物资
```

在这个 [Sub-issue](./issue-collaboration-guidelines.zh.md) 中集中记录需要准备的物品、数量、来源、预计获取时间和当前状态。普通规模的活动不必为了形式单独建立物资任务，但仍应完成本文档中的相关检查。

## 第一步：先确认活动需求

在购买或借用物资之前，先根据活动信息判断需要什么：

- 活动预计有多少人，报名人数是否还可能增加
- 活动在哪里举行，场地能容纳多少人
- 是否需要桌椅、签到、食品饮料、奖品或嘉宾接待
- 是否需要电脑、投影、音响、麦克风、转接头或网络
- 是否属于运动、户外或有一定安全风险的活动
- 哪些物品必须提前获得，哪些可以当天临时补充

报名人数如果明显超过原计划，应重新评估场地、桌椅、食品、签到和现场动线。不要只增加采购数量后继续使用不合适的场地。

## 第二步：先找现有物资，再决定采购

### 检查学校和活动库存

采购前，先确认学校、书院、公共空间或此前活动是否有可用物资。例如：

- 此前活动剩余的包装食品和饮料
- 文具、装饰物、纸巾、垃圾袋等消耗品
- 可以借用的桌椅、电脑、投影、音响或其他设备

使用此前活动剩余食品时，要检查保质期、包装完整性和是否适合继续分发。

### 需要食品饮料时

- 需要新鲜度的食品和饮料，尽量线下购买。
- 包装零食、瓶装饮料等可以提前线上购买。
- 如果需要校内 C19 天猫超市挂账，应提前联系[Beta College 辅导员](https://github.com/BETA-SDC/community-private-information/blob/main/text/contacts/general.md#role-beta-college-counselor)确认挂账方式、可购买范围和联系方式。
- 不要等到活动当天才确认挂账流程。

如果需要线下采购新鲜食品、饮料或临时补充物资，可以考虑：

```text
盒马鲜生（龙湖杭州西溪天街店）
浙江省杭州市西湖区蒋村街道余杭塘路1001号龙湖杭州西溪天街B1层
```

线下采购前先确认购物清单、预算、发票要求和返回学校的交通方式。

### 需要线上购买时

实体奖品、定制物、包装物和不易变质的小零食可以线上购买。实体奖品尤其要提早下单，给快递和可能的补发留出时间。不能等到活动临近才购买必须使用的奖品。

## 第三步：按活动场景准备物资

### 奖品和嘉宾

- 实体奖品、定制物和需要快递的物品应尽早购买。
- 需要批量购买的奖品应提前确认数量和送达时间。
- 邀请嘉宾时，可以准备咖啡、饮用水等合适的物资。
- 提前确认嘉宾是否需要接待、引导或等待空间。

### 签到

- 根据提前收集的报名信息打印签到表。
- 签到表必须预留空位，供未报名但实际到场的人填写。
- 现场签到时注意记录临时到场、取消或其他异常情况。
- 活动结束后，按 [签到记录整理规范](./sign-in-record-guidelines.zh.md) 整理数据来源、统计口径和名单。

### 场地、桌椅和布置

- 场地应根据预计人数选择。
- 如果报名人数过多，应尽早更换到更合适的场地。
- 如果活动在 H4 班活动空间举行，桌椅优先从 `H4-103`、`H4-104` 搬取。
- 如果桌椅仍然不够，可以找门口的管家协助打开其他房间。
- 搬动桌椅后应注意保持房间秩序，活动结束后尽量恢复原状。
- 同时确认纸巾、垃圾袋、一次性餐具和活动后清理安排。

### 运动和安全

运动类、户外类或有一定安全风险的活动，应提前准备基础医疗物品。可以根据活动风险准备：

- 创可贴
- 碘伏棉签或消毒湿巾
- 纱布和医用胶带
- 冰袋或冷敷贴
- 一次性手套
- 纸巾和湿巾
- 处理常见扭伤、擦伤所需的基础用品

如果活动风险较高，还应提前确认附近可求助人员、场地管理人员或校内应急联系方式。本文档只提供活动准备提醒，不替代专业医疗建议。

### 媒体和设备

如果活动需要播放音乐、展示 PPT、放映视频、进行线上会议或录音录像，应提前调试：

- 电脑和演示文件
- 投影仪和屏幕
- 音响和麦克风
- 转接头、电源和充电设备
- 网络和播放素材

不要等到活动开始前才第一次连接设备。如果需要拍照或录像，同时参考 [素材拍摄与交付规范](./media-capture-guidelines.zh.md)，提前确认设备、授权、存储位置和活动后上传方式。

## 第四步：整理支出和凭证

### 需要保留什么

- 除校内挂账外，所有支出都需要发票。
- 打车除发票外还需要行程单。
- 打车报销时，起点和终点中至少一个应为学校。
- 不要只保留聊天记录中的付款截图。

### 交给谁整理

账单、发票、行程单等 PDF 或图片凭证交给活动负责人统一整理。发票抬头、税号、金额、购买内容、购买时间、打车起终点等信息，不要只保存在 PDF 或图片里，还应按照 [invoice 报销仓库](https://github.com/BETA-SDC/invoice) 的格式整理到相关记录中。填写发票抬头时可参考[发票抬头信息](https://github.com/BETA-SDC/invoice/blob/main/invoice-title.txt)，整理结构化票据时可参考[票据 YAML 模板](https://github.com/BETA-SDC/invoice/tree/main/templates)。

## 活动前最后检查

- [ ] 已确认活动人数、场地容量和桌椅数量是否匹配
- [ ] 已检查学校、书院或此前活动的库存
- [ ] 实体奖品、定制物和快递物资已提前购买
- [ ] 食品饮料已根据新鲜度选择线上或线下采购
- [ ] C19 天猫超市挂账方式已提前向[Beta College 辅导员](https://github.com/BETA-SDC/community-private-information/blob/main/text/contacts/general.md#role-beta-college-counselor)确认
- [ ] 线下采购的地点、预算、发票和交通方式已确认
- [ ] 签到表已打印，并预留未报名到场人员的空位
- [ ] 嘉宾饮品、接待和引导安排已确认
- [ ] 运动类活动已准备基础医疗物品
- [ ] 电脑、投影、音响、网络和转接头已经调试
- [ ] 非校内支出已提醒保留发票
- [ ] 打车已提醒保留发票和行程单，并确认起点或终点为学校
- [ ] 账单、发票、行程单和支出信息已交给活动负责人整理
