# 活动物资准备参考指南

中文 | [English](./activity-material-preparation-guidelines.md)

> 本文档用于在筹备活动物资时提供参考。当成员不确定应提前准备什么、如何采购、如何检查遗漏时，可以先按本文档梳理。不同活动规模和形式不同，实际执行时应根据活动负责人、场地、预算和报名情况灵活调整。

## 使用场景

活动涉及以下任一情况时，建议提前查看本文档：

- 需要购买食品、饮料、奖品、嘉宾礼品或装饰物
- 需要打印签到表、准备签到用品或现场补录名单
- 需要搬运桌椅、确认场地容量或布置活动空间
- 需要使用电脑、投影、音响、麦克风等媒体设备
- 需要准备运动、户外或有一定安全风险的活动物资
- 活动支出需要发票、行程单或后续报销整理

大型活动、物资种类较多的活动，或涉及嘉宾、媒体设备、运动风险的活动，建议在活动主 Issue 下单独建立 `[task] 活动名称 - 准备物资` Sub-issue，用于跟踪物资状态、负责人确认和活动前检查。

## 基本原则

- **先确认现有库存。** 采购前先确认学校、书院或此前活动是否已有可用物资，例如上次活动剩余食品、文具、装饰物或常用设备。
- **提前处理长周期物资。** 实体奖品、定制物、需要快递配送的物品应尽早购买，避免临近活动时物流无法送达。
- **食品饮料注意新鲜度。** 需要新鲜度的食品饮料尽量线下购买；可以长期保存的小零食可以提前线上购买。
- **物资数量跟随报名情况调整。** 报名人数明显超过原计划时，应同步评估场地、桌椅、食品、签到和现场动线，而不是只增加采购数量。
- **支出凭证及时整理。** 除校内挂账外，所有支出都应保留发票；打车还需要行程单，且起点和终点中至少一个应为学校。

## 采购和获取渠道

### 学校和活动库存

准备物资前，优先确认是否已有库存可用。可检查此前活动剩余物资、公共空间常备物资或学校可借用设备。若使用此前活动剩余食品，应注意保质期、包装完整性和是否适合继续分发。

### 校内 C19 天猫超市

食品饮料或临时补给可以优先考虑校内 C19 天猫超市。若需要挂账，应提前联系辅导员确认挂账方式、可购买范围和联系方式，不要到现场后再临时确认。

### 线下采购

如果需要新鲜食品、饮料或临时补充物资，可以前往：

```json
{
  "name": "盒马鲜生(龙湖杭州西溪天街店)",
  "address": "浙江省杭州市西湖区蒋村街道余杭塘路1001号龙湖杭州西溪天街B1层"
}
```

线下采购前应确认预算、购买清单、是否需要发票，以及返回学校的交通方式。打车报销时需要保留行程单，且起点和终点中至少一个应为学校。

### 线上采购

实体奖品、定制物、包装物或不易变质的小零食可以线上购买。线上采购应尽量留出物流缓冲时间，避免活动前一天才下单。若奖品与活动流程强相关，应准备替代方案或提前确认预计送达时间。

## 常见物资提醒

### 奖品和嘉宾物资

实体奖品应提早购买，尤其是需要快递、定制或批量采购的奖品。邀请嘉宾参加活动时，可以根据活动场景准备咖啡、饮用水或其他合适的小物资，并提前确认是否需要接待、引导或休息空间。

### 食品和饮料

食品饮料应根据报名人数、活动时长、活动时间段和场地限制准备。需要新鲜度的食品尽量线下购买；包装零食、瓶装饮料等可以提前采购。活动前应确认是否需要一次性餐具、纸巾、垃圾袋，以及活动后清理安排。

### 签到和现场补录

有报名的活动应根据提前收集的信息打印签到表。签到表应预留空位，给未报名但实际到场的参与者填写。活动结束后，如需整理到场统计，应按 [签到记录整理规范](./sign-in-record-guidelines.zh.md) 保存数据来源、统计口径和异常说明。

### 场地和桌椅

场地选择应根据预计人数提前确认。如果前期报名人数明显超过原场地容量，应及时选择其他场地，而不是只在现场临时增加座位。

如果活动在 H4 班活动空间举行，桌椅优先从 H4-103、H4-104 搬取。若仍不够，可以联系门口管家协助打开其他房间。搬动桌椅前后应注意不要影响原有房间秩序，活动结束后尽量恢复原状。

### 运动和安全物资

运动类、户外类或有一定安全风险的活动，应提前准备基础医疗物品。建议根据活动风险准备：

- 创可贴
- 碘伏棉签或消毒湿巾
- 纱布和医用胶带
- 冰袋或冷敷贴
- 一次性手套
- 纸巾和湿巾
- 常见扭伤、擦伤处理所需的基础用品

如活动风险较高，应提前确认附近可求助人员、场地管理人员或校内应急联系方式。本文档只提供活动准备提醒，不替代专业医疗建议。

### 媒体和设备

需要播放音乐、展示 PPT、放映视频、线上会议或录音录像的活动，应提前调试电脑、投影、音响、麦克风、转接头、网络和电源。不要等到活动开始前才第一次连接设备。

如活动需要拍照或录像，应同时参考 [素材拍摄与交付规范](./media-capture-guidelines.zh.md)，提前确认拍摄设备、授权要求、素材保存位置和活动后上传方式。

## 支出和凭证整理

除校内挂账外，所有支出都需要开发票。打车除发票外还需要行程单，且起点和终点中至少一个应为学校。

账单、发票等 PDF 或图片凭证应交给活动负责人统一整理。发票抬头、税号、金额、购买内容、打车起终点、购买时间等信息，应按规定格式整理到 `invoice` 相关记录中，便于后续报销和复核。

> [!IMPORTANT]
> 不要只在聊天记录里发送付款截图。活动负责人需要能追溯每一笔支出的用途、凭证和对应活动。

## 活动前检查清单

- [ ] 已确认是否有学校、书院或此前活动库存可用
- [ ] 实体奖品、定制物或需要快递的物品已提前下单
- [ ] 食品饮料已按新鲜度选择线上或线下采购方式
- [ ] 如需 C19 天猫超市挂账，已提前联系辅导员确认方式
- [ ] 如需线下采购，已确认采购地点、预算、发票和交通方式
- [ ] 有报名的活动已打印签到表，并预留现场补录空位
- [ ] 场地容量、桌椅数量和报名人数已经匹配
- [ ] H4 场地活动已确认桌椅来源和活动后恢复安排
- [ ] 嘉宾相关饮品、接待或引导安排已确认
- [ ] 运动类活动已准备基础医疗物品
- [ ] 需要媒体设备的活动已提前调试电脑、投影、音响、网络和转接头
- [ ] 所有非校内支出已提醒保留发票，打车已提醒保留行程单
- [ ] 账单、发票和支出信息已交由活动负责人统一整理
