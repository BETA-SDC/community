# 素材拍摄与交付规范

中文 | [English](./media-capture-guidelines.md)

## 适用场景

本规范面向小组织的官网展示、活动记录和非专业人员剪辑使用。目标是让素材清晰、统一、方便整理和复用，不追求专业影视制作规格。

## 通用要求

| 项目 | 建议 | 说明 |
|---|---|---|
| 画面方向 | **横屏拍摄** | 官网展示和常规视频剪辑优先使用横屏素材 |
| 画面比例 | **16:9** | 视频和照片保持统一，减少后期二次裁切 |
| 文件格式 | **常见通用格式** | 视频使用设备默认格式，照片统一使用 JPEG |
| 画面稳定 | **尽量保持稳定** | 避免快速甩动、频繁变焦和边走边拍 |
| 光线 | **优先选择明亮环境** | 避免背光、过暗、强烈彩色灯光导致人物看不清 |
| 构图 | **主体完整、背景干净** | 人物头顶和身体边缘留出空间，避免重要内容贴边 |

## 视频

### 设备：大疆 Pocket 3

| 参数 | 建议 | 说明 |
|---|---|---|
| 图像比例 | **16:9** | 横屏通用，后期可裁竖屏 |
| 分辨率 | **4K** | 给裁切和防抖留余量 |
| 帧率 | **30fps**（日常）/ **60fps**（要慢动作） | 通用流畅，60fps 后期放慢丝滑 |

### 拍摄注意事项

- 每个镜头尽量保持 **5-10 秒**，不要刚开始拍就立刻停止。
- 拍摄人物讲话、展示、互动时，先稳定画面 **1-2 秒** 再开始移动。
- 尽量少用数码变焦；需要靠近时，优先移动设备或重新构图。
- 现场有讲话、采访、讲解时，尽量靠近声源，避免站在人群后方远距离录音。
- 如果同一场景很重要，可以补拍一条全景、一条中景、一条细节，方便后期剪辑。

## 照片

### 设备：相机

| 参数 | 建议 | 说明 |
|---|---|---|
| 图像比例 | **16:9** | 和视频比例统一，方便直接进入剪辑 |
| 分辨率 | **默认/标准分辨率即可** | 满足官网展示和普通剪辑使用，避免文件过大 |
| 格式 | **JPEG** | 通用性最好，剪辑软件都认 |

> 注：相机照片的 16:9 通常也是从传感器原生比例中裁切得到。拍摄时上下多留一点空间，避免人物头顶、脚部或建筑顶部被切掉。

### 手机（代替）

| 参数 | 建议 | 说明 |
|---|---|---|
| 图像比例 | **16:9** | 和视频比例统一，减少剪辑前二次裁切 |
| 像素 | **默认像素即可** | 满足官网展示和普通剪辑使用，避免文件过大、传输变慢 |
| 格式（iPhone） | **兼容性最佳（JPEG）** | 通用性最好，剪辑软件都认 |
| 格式（安卓） | **JPEG** | 通用性最好，剪辑软件都认 |

### 拍摄注意事项

- 每个重要场景至少拍 **2-3 张**，方便后续筛选表情、闭眼和虚焦问题。
- 人物合影尽量保证脸部清楚、无遮挡，不要只拍背影或远景。
- 拍摄展板、海报、屏幕、白板时，尽量正对拍摄，避免倾斜和反光。
- 拍摄环境照时，注意保留地点特征，例如门头、活动背景板、工作场景或关键设备。
- 不需要额外开启美颜、滤镜或强风格化调色，避免不同设备素材风格差异过大。

## 内容安全

- 拍摄屏幕、白板、文档、群聊和工牌时，先确认没有敏感信息。
- 涉及未成年人、嘉宾、外部合作方或不适合公开露出的人物时，发布前需要确认授权。
- 避免上传明显不适合官网展示的素材，例如表情尴尬、姿态不雅、画面杂乱或背景有无关广告。
- 不要对照片进行过度修图或加滤镜，保持真实、清晰、统一的组织形象。

## 素材交付

| 项目 | 建议 | 说明 |
|---|---|---|
| 筛选 | **先删除明显不可用素材** | 例如严重模糊、误触拍摄、人物闭眼、画面过暗 |
| 保留 | **重要场景保留多张/多条** | 不要只留一张，方便后续选择更合适的画面 |
| 命名 | **按日期和活动整理文件夹** | 例如 `2026-09-16-activity-name` |
| 上传 | **尽量上传原文件** | 不要通过聊天软件反复压缩后再交付 |
| 说明 | **补充简单文字说明** | 标注活动名称、拍摄时间、地点和关键人物，方便后续查找 |

> [!IMPORTANT]
> 活动照片和视频应上传到 [Beta College Album](https://westlakeu.sharepoint.com/sites/beta-college/Album/Forms/AllItems.aspx?viewid=f4bff7b2%2Ddd12%2D43eb%2Da665%2Dd945dfd194c3)。上传时按日期和活动名称建立文件夹，并尽量保留原文件，避免只把素材留在聊天记录或个人设备中。
