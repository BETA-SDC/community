# BETA-SDC 素材拍摄与交付

这个 Skill 用于活动照片、视频的拍摄计划、现场执行、内容安全检查、筛选、命名和交付。

## 基本目标

素材应清晰、稳定、统一、方便后期剪辑和官网展示。不追求专业影视制作规格，但要保证可用性和可追溯性。

## 通用设置

- 画面方向：横屏优先
- 画面比例：16:9
- 视频：设备默认通用格式，日常 Pocket 3 使用 4K、30fps；慢动作使用 60fps
- 照片：JPEG
- 画面：稳定，避免快速甩动、频繁变焦和边走边拍
- 光线：优先明亮环境，避免背光、过暗和强烈彩色灯光
- 构图：主体完整，背景干净，重要内容不要贴边

## 视频拍摄

- 每个镜头尽量保持 5-10 秒。
- 人物讲话、展示和互动时，先稳定 1-2 秒再移动。
- 少用数码变焦；需要靠近时移动设备或重新构图。
- 讲话、采访或讲解时靠近声源。
- 重要场景补拍全景、中景和细节。

## 照片拍摄

- 重要场景至少拍 2-3 张。
- 合影保证脸部清楚、无遮挡，不要只拍背影或远景。
- 展板、海报、屏幕、白板尽量正对，避免倾斜和反光。
- 环境照保留门头、背景板、工作场景或关键设备等地点特征。
- 不额外开启美颜、滤镜或强风格化调色。

## 内容安全

拍摄屏幕、白板、文档、群聊和工牌前，确认没有敏感信息。

涉及以下人物时，发布前确认授权：

- 未成年人
- 嘉宾
- 外部合作方
- 不适合公开露出的人员

不要上传明显不适合官网展示的素材，例如：

- 严重尴尬的表情
- 姿态不雅
- 画面杂乱
- 背景有无关广告
- 明显模糊、误触、闭眼或过暗

## 筛选和交付

1. 先删除明显不可用素材。
2. 重要场景保留多张照片或多条视频，方便后期选择。
3. 按日期和活动名称建立文件夹，例如 `2026-09-16-activity-name`。
4. 尽量上传原文件，不要通过聊天软件反复压缩。
5. 附简单说明：活动名称、拍摄时间、地点和关键人物。
6. 上传到 Beta College Album，不要只留在聊天记录或个人设备。

## 交付说明模板

```markdown
## 素材说明

- 活动名称：
- 拍摄日期：
- 拍摄地点：
- 文件夹：
- 关键人物或场景：
- 授权或敏感信息检查：
- Album 链接：
- 需要后期注意的问题：
```

## 完成检查

- 横屏和 16:9 素材优先。
- 视频片段长度和画面稳定性基本可用。
- 重要场景有备选素材。
- 屏幕、文档、群聊和工牌无敏感信息。
- 需要授权的人员已确认。
- 不可用素材已筛除。
- 文件夹按日期和活动名称命名。
- 原文件已上传 Album。
- 活动主 Issue 或 `[wrap-up]` 记录已链接素材位置。

## 禁止事项

- 不要只拍一张重要场景。
- 不要依赖聊天软件压缩后的唯一副本。
- 不要把原始素材只放在个人设备。
- 不要用过度滤镜替代清晰、稳定和正确曝光。
- 不要在未确认敏感信息或授权的情况下公开上传。
